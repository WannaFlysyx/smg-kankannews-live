## 📦 安装
### 前置要求
浏览器需要预先安装脚本管理器扩展，任选其一：
- [Tampermonkey（油猴）](https://www.tampermonkey.net)
- [ScriptCat（脚本猫）](https://docs.scriptcat.org)
- [Violentmonkey（暴力猴）](https://violentmonkey.github.io/get-it/)
